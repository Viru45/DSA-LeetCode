# Java Practice & DSA

A collection of Java programs covering basic concepts, LeetCode challenges, and Data Structure implementations.

## 📌 Project Goals
- To strengthen my understanding of Java syntax and logic.
- To practice problem-solving using Data Structures and Algorithms (DSA).
- To maintain a consistent coding habit.

## 📂 Folders
- **/Basics**: Primitive types, loops, and conditions.
- **/OOP**: Classes, inheritance, and interfaces.
- **/LeetCode**: Solutions to competitive programming problems.
- **/DataStructures**: Implementation of Lists, Stacks, Queues, and Trees.
